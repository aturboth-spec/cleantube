# 클린튜브

유튜브 동영상 광고를 자동으로 넘기고, 화면을 꺼도 계속 재생되게 하는 유저스크립트입니다.

## 휴대폰 설치 (Firefox + Violentmonkey)

1. 휴대폰 **Firefox**로 이 페이지를 엽니다.
2. 아래 링크를 누릅니다.

   👉 **[클린튜브 설치하기](https://raw.githubusercontent.com/aturboth-spec/cleantube/main/cleantube.user.js)**

3. Violentmonkey 설치 화면이 열리면 **설치**(또는 확인)를 누릅니다.
4. Firefox에서 `m.youtube.com`에 들어가 사용합니다.

## 업데이트

이 저장소의 `cleantube.user.js`를 고쳐 올리면 Violentmonkey가 자동으로 새 버전을 받습니다.
바로 받으려면 Violentmonkey 대시보드에서 **업데이트 확인**을 누르세요.
(새 버전을 올릴 때는 파일 위쪽의 `@version` 숫자를 올려야 합니다.)
